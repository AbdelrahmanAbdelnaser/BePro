# SDLC Methodology

i use waterfall model becouse this a simple and light project written with only html and css

SDLC phases

---requirements phase
-define platform feature
-Identify target users
-demonstrate what system need

---design phase
in this phase we will create
-layout for pages
-design pages
-choose color and UI components

--Implementation phase
in this phase
-we will create pages html
-make style with css
-make some logic with js

--testing phase
in this phase our app will be tested
-we will test forms validation
-test responsive
-test check layout
-fix bugs we found

--Deployment phase
in this phase the website will be prepared for delivary
-orgnize files and folders
-upload the project to hosting

--Maintenance phase
-Improve design
-improve logic
-update contents
